# Calculadora

Calculadora web desarrollada como proyecto de portafolio.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Características

- Operaciones básicas
- Multiplicación y división
- Porcentajes
- Paréntesis
- Botón AC
- Botón de borrar
- Diseño responsive
- Tipografía Lato
